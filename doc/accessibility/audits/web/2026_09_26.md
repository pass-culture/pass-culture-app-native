<summary> ⏳ Critère 7.5 - Dans chaque page web, les messages de statut sont-ils correctement restitués par les technologies d'assistance ?</summary>

**RGAA** : [Critère 7.5](https://accessibilite.numerique.gouv.fr/methode/criteres-et-tests/#7.5)  
**Ticket** : [PC-42997](https://passculture.atlassian.net/browse/PC-42997)  
**PR** : [#XXXX](https://github.com/pass-culture/pass-culture-app-native/pull/XXXX)

**Problème** 😱

- **[ P01 - Création de compte ]**: La mise à jour du respect des critères dans le choix d'un mot de passe n'est pas restituée aux technologies d'assistance.
- **[ P10 - Réservation d'une offre ]**: Le message "Le lien a été copié dans le presse-papier !" (bouton "Copier" de la fenêtre modale "Partager l'offre") n'est pas restitué aux technologies d'assistance.
- **[ P13 - Vérification d'identité (étape profil) ]**: Le message "Une erreur est survenue lors de la mise à jour de ton profil" apparaît sans être restitué aux technologies d'assistance.

**Correction** 💡

- **[ Toutes les pages ]** : Ajout d'un composant `LiveRegion` monté en permanence à la racine du document. Les messages de statut y sont insérés après coup, ce qui est la condition pour que les lecteurs d'écran les vocalisent (une région live créée en même temps que son contenu n'est pas restituée de façon fiable).
- **[ Toutes les pages ]** : La snackbar du design system alimente cette région avec `role="status"` (`aria-live="polite"`) pour les messages de succès et `role="alert"` (`aria-live="assertive"`) pour les messages d'erreur. Le message reste dans la région après la disparition visuelle de la snackbar, ce qui laisse le lecteur d'écran terminer sa vocalisation sans allonger la durée d'affichage.
- **[ P01 - Création de compte ]** : Ajout d'une région live sur les critères de mot de passe, qui annonce uniquement les critères passant à l'état validé (et non la liste complète à chaque frappe).
- **[ P08 - Recherche ]** : Correction de `AccessibilityRole.STATUS`, qui produisait `role="presentation"` au lieu de `role="status"` sur les messages indiquant le nombre de résultats.

**Retours audit** 🔥
